Entry point · one identity, native everywhere

Same app, each platform's own controls

Identical behaviour (type in, first line = title, ＋ New = divider + fresh section). The identity is Things 3 × Apple Reminders; each build then obeys its platform's native conventions.

Why three? Circles & iOS-blue feel right on Apple, but a Windows user expects Fluent square checkboxes + Segoe + an accent button, and an Android user expects Material checkboxes, Roboto, and a floating action button. Native beats consistent-but-foreign.
